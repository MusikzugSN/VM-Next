## Lokaler Druckservice

Für größere Druckaufträge können Sie einen Druckservice auf Ihrem eigenen Rechner installieren. Er läuft nur auf Ihrem Rechner und ist nur von dort erreichbar.

Das druckfertige PDF erzeugt der VM-Web-Server wie bei einem Download. Ihr Browser gibt es direkt an den Druckservice auf Ihrem Rechner weiter, der es an Ihren Drucker schickt. Druckerauswahl, Status und Verlauf Ihrer Druckaufträge speichert der Druckservice nur auf Ihrem Rechner. An den VM-Web-Server werden keine Druckdaten übertragen.
